你实现的分布式缓存一致性协议模块存在一些问题，需要修复：
1. Lock 方法在收到其他节点的锁拒绝消息后立即返回错误，但此前已向某个节点授予锁的临时锁记录未被清理。该节点在锁 TTL 期间持续认为请求者持锁，后续任何节点向该节点发起同 key 锁请求都会被错误拒绝。
2. cachesync.go 中声明的 ErrVersionTooOld 错误变量在整个包的任意函数中都未被引用或返回，handleUpdateNotify 对版本号不高于本地的更新消息仅做静默忽略，版本拒绝事件完全不可观测。
3. docs/cachesync.md 文档正文在"版本化更新通知流程"的流程图绘制到一半时截断，后续的写入无效化广播流程、锁协商消息流转路径、对账修复流程和 API 使用示例均缺失，不满足提示词第 7 条需求。
4. 修复后运行 go test ./internal/cachesync/ -v，需要让所有测试通过。需要补充验证锁拒绝后各节点状态是否正确回滚和多节点对账修复的测试用例。
5. 在 docs/cachesync.md 中补全文档，说明修复后的锁协议状态回滚机制、版本拒绝可观测性和完整的消息流转路径。
