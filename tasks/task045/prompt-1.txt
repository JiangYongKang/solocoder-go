在当前项目中实现一个 API 密钥管理器功能模块。
1. 实现密钥生成：支持创建新的 API 密钥，生成唯一密钥标识和密钥值，密钥值采用安全随机生成且生成后仅在创建时返回完整明文一次，后续仅可通过密钥标识前缀匹配查询密钥元信息而无法再次获取密钥明文。
2. 实现权限范围绑定：创建密钥时可指定该密钥的权限范围，支持按资源类型和操作类型定义细粒度的访问权限，例如只读权限、特定资源写入权限等，校验请求时判断密钥的权限范围是否覆盖请求的操作。
3. 实现使用次数限制：每个密钥可设置最大使用次数上限，每次使用密钥成功认证后计数器递增，达到上限后该密钥自动失效，同时支持剩余使用次数的查询，计数器应保证并发场景下的准确性。
4. 实现过期时间设置：密钥创建时可设置有效期，到达过期时间后密钥自动失效不可继续使用，过期时间支持绝对时间戳和相对时长两种设置方式，可查询密钥的剩余有效时间。
5. 实现密钥泄露后的紧急吊销：提供紧急吊销接口，输入密钥标识后可立即将该密钥标记为已吊销状态并记录吊销时间和原因，已吊销的密钥在所有校验中均视为无效，吊销操作不可逆。
6. 代码实现和单测需要放在 internal/apikey/ 包下，然后为该模块编写完整的单元测试，覆盖正常流程、边界条件和异常分支。
7. 运行 go test ./internal/apikey/ -v，需要让所有测试通过。
8. 在 docs/apikey.md 中编写模块需求文档，说明模块功能、核心结构体的职责、密钥从生成到吊销的完整生命周期以及使用示例。
