在当前项目中实现一个 A/B 测试流量分割器功能模块。
1. 实现按用户 ID 哈希分桶：接收用户标识后通过哈希函数将用户稳定分配到 0 到 99 的 100 个桶中的一个，同一用户多次调用分桶结果始终相同不因系统重启或时间变化而漂移，哈希分桶作为实验流量分配的基础机制所有实验都基于该分桶结果决定用户进入哪个实验组。
2. 实现多实验正交流量分配：支持创建多个独立的 A/B 实验每个实验拥有自己的实验组和对照组的流量比例配置，多个实验的流量分配互不干扰即正交分配，同一用户可能同时参与多个实验但每个实验中该用户只属于一个分组，用户在每个实验中的分组通过在用户原始哈希值上叠加实验 ID 哈希后重新计算桶号来确定确保各实验间的分配相互独立。
3. 实现实验组与对照组的流量比例配置：每个实验支持独立配置实验组和对照组的流量占比百分比两者之和不超过 100，剩余流量标记为不参与实验，用户被分配到实验组时返回实验版本的标识分配到对照组时返回对照版本的标识分配到不参与部分时返回未命中实验的标识。
4. 实现实验效果指标采集：为每个实验的每个分组提供指标上报接口支持记录用户的行为事件和对应的指标值，指标数据按实验 ID 和分组分别累计最终可查询每个实验各组的总事件数和指标汇总值用于对比分析实验效果。
5. 代码实现和单测需要放在 internal/abtest/ 包下，然后为该模块编写完整的单元测试，覆盖正常流程、边界条件和异常分支。
6. 运行 go test ./internal/abtest/ -v，需要让所有测试通过。
7. 在 docs/abtest.md 中编写模块需求文档，说明模块功能、核心结构体的职责、正交流量分配的算法原理以及使用示例。
