在当前项目中实现一个请求级性能采样器功能模块。
1. 实现 CPU Profiling 数据采集：支持对单个请求处理过程的 CPU 使用情况进行采样，记录函数调用栈和各函数的 CPU 时间占比，采样数据以结构化的调用栈节点形式存储。
2. 实现内存 Profiling 数据采集：支持对单个请求处理过程的内存分配情况进行采样，记录各函数的分配次数和分配字节数，采样粒度到函数级别。
3. 实现耗时 Profiling 数据采集：支持对单个请求处理过程中各阶段的耗时进行分段计时，记录每个阶段的开始时间和持续时长，阶段可按用户自定义标签划分。
4. 实现采样率配置：支持按请求比例配置采样率如 10% 的请求被采样，未被采样的请求不产生 Profiling 开销，采样决策在请求开始时一次性确定。
5. 实现采样结果导出：将单次请求的 Profiling 采样数据导出为结构化对象包含 CPU 调用栈、内存分配统计和耗时分段信息，导出对象可序列化为 JSON 格式。
6. 实现火焰图数据格式生成：将 CPU 采样的调用栈数据转换为火焰图兼容的数据格式，每条记录包含函数名和采样计数值，多条记录的父子关系通过调用栈层级表达。
7. 代码实现和单测需要放在 internal/perfsampler/ 包下，然后为该模块编写完整的单元测试，覆盖正常流程、边界条件和异常分支。
8. 运行 go test ./internal/perfsampler/ -v，需要让所有测试通过。
9. 在 docs/perfsampler.md 中编写模块需求文档，说明模块功能、核心结构体的职责、三种 Profiling 维度的数据结构和火焰图格式说明以及使用示例。
