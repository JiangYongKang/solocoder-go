在当前项目中实现一个 JWT 令牌管理器功能模块。
1. 实现 HS256/RS256 双算法签发：支持使用 HMAC-SHA256 对称密钥和 RSA-SHA256 非对称密钥两种方式签发 JWT，签发时设置签发者、主题、受众、过期时间和自定义声明等标准字段，签发后的 Token 格式需符合 RFC 7519 规范。
2. 实现声明校验：提供 Token 验证能力，校验 Token 签名是否有效、是否过期、签发者是否匹配、受众是否包含当前服务等，任意一项校验不通过返回对应的错误信息。
3. 实现黑名单吊销：支持将指定 Token 的唯一标识（jti）加入黑名单，已加入黑名单的 Token 即使未过期也视为无效，黑名单支持基于内存的存储，并提供按 TTL 自动清理过期记录的能力。
4. 实现令牌续期：当访问令牌即将过期或刚过期但仍在可续期窗口内时，允许使用该令牌换取一个新的访问令牌，新令牌保留原令牌的声明信息并设置新的过期时间，续期后的旧令牌可配置为自动加入黑名单。
5. 实现刷新令牌轮换：签发访问令牌时可同时返回刷新令牌，客户端使用刷新令牌换取新访问令牌时签发全新的刷新令牌并使旧刷新令牌失效，防止刷新令牌被截获后长期滥用。
6. 代码实现和单测需要放在 internal/jwtmgr/ 包下，然后为该模块编写完整的单元测试，覆盖正常流程、边界条件和异常分支。
7. 运行 go test ./internal/jwtmgr/ -v，需要让所有测试通过。
8. 在 docs/jwtmgr.md 中编写模块需求文档，说明模块功能、核心结构体的职责、令牌签发与校验的完整流程以及使用示例。
