在当前项目中实现一个多级缓存架构功能模块。
1. 实现 L1 与 L2 级联查询：支持 L1 内存缓存和 L2 磁盘缓存的两级架构，查询时先检查 L1，未命中再查 L2，L2 命中后将数据回填到 L1 中以加速后续访问。
2. 实现写入穿透策略配置：支持配置写入时采用的策略，包括双写模式同时更新 L1 和 L2，以及回写模式仅更新 L1 后在指定时机异步刷入 L2。
3. 实现各级容量独立控制：L1 和 L2 各自维护独立的容量上限，容量以条目数量或内存字节数为单位可配置，各级超出容量时触发各自的淘汰策略。
4. 实现缓存淘汰策略：支持为各级缓存配置不同的淘汰策略，内置 LRU 最近最少使用淘汰算法，当缓存达到容量上限时按淘汰策略逐出条目腾出空间。
5. 代码实现和单测需要放在 internal/tieredcache/ 包下，然后为该模块编写完整的单元测试，覆盖正常流程、边界条件和异常分支。
6. 运行 go test ./internal/tieredcache/ -v，需要让所有测试通过。
7. 在 docs/tieredcache.md 中编写模块需求文档，说明模块功能、核心结构体的职责、数据在多级缓存间的流转路径以及使用示例。
