你实现的 IP 地理定位模块存在一些问题，需要修复：

1. findLongestPrefixMatch 方法在二分定位候选起点后采用向后线性遍历匹配 CIDR，当查询 IP 不在任何 CIDR 范围内时遍历不会提前终止，会回溯检查全部已排序条目，最坏时间复杂度退化为 O(n)，与通过二分查找避免全量线性扫描的目标矛盾。

2. ipgeo.go 中定义了 sortedIndex 结构体，包含 entries 和 count 字段，但该结构体在包内从未被任何函数引用或实例化，属于遗留的死代码。

3. 导出的 CountLeadingZeros32 函数封装了标准库的 bits.LeadingZeros32，有对应的测试用例但从未被任何生产代码调用，与 IP 地理定位核心功能无关。

4. parseDataLine 函数解析不带显式多语言标记的基础数据行时，将中文字段同时写入了中文和英文两个语言映射。当用英文语言编码查询时，英文映射中存在非空的中文字符串，不会触发语言降级回退逻辑。

5. 修复后运行 go test ./internal/ipgeo/ -v，需要让所有测试通过。
