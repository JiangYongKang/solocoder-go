在当前项目中实现一个 IP 地理位置查询引擎功能模块。
1. 实现基于 CIDR 段的 IP 归属查询：加载包含 CIDR 网段与地理位置映射关系的数据集，查询时将输入 IP 地址与 CIDR 网段逐条匹配，找到包含该 IP 的最具体网段即最长前缀匹配并返回对应的地理位置信息，未匹配到任何网段时返回未找到结果。
2. 实现 IP 库的内存二分查找索引：将 CIDR 网段按起始 IP 排序后在内存中构建二分查找索引，查询时通过二分查找快速定位候选网段再精确匹配，避免全量线性扫描以提升大规模 IP 库的查询性能。
3. 实现 IP 库热更新：支持在不重启服务的情况下加载新的 IP 库数据文件，加载期间查询请求仍由旧索引服务不受影响，新数据加载完成后原子切换索引，旧索引在新索引稳定后释放。
4. 实现多语言返回结果：地理位置查询结果支持返回多种语言的地区名称，调用方在查询时指定期望的语言编码，引擎根据语言编码返回对应语言的省市区名称文本。
5. 代码实现和单测需要放在 internal/ipgeo/ 包下，然后为该模块编写完整的单元测试，覆盖正常流程、边界条件和异常分支。
6. 运行 go test ./internal/ipgeo/ -v，需要让所有测试通过。
7. 在 docs/ipgeo.md 中编写模块需求文档，说明模块功能、核心结构体的职责、CIDR 最长前缀匹配的查找流程、热更新的原子切换机制以及使用示例。
