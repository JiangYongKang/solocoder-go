你实现的舱壁隔离模块存在一些问题，需要修复：
1. bulkhead.go 的 canSubmit 方法中 idleWorkers 大于 0 时直接返回 true 绕过了队列容量限制，当队列已满但有空闲 worker 时新任务仍被追加到队列中，特别是在队列缩容场景下队列长度会暂时超过配置的容量上限，需要修复为队列满时一律拒绝新任务。
2. 提示词要求"通过信号量机制控制每个隔离舱的并发执行数量"，但当前实现是 worker 协程池模式没有提供独立的信号量接口，调用方无法在自己的 goroutine 中获取和释放并发槽位执行受保护代码，需要补充带超时的信号量 Acquire 和 Release 方法。
3. 修复后运行 go test ./internal/bulkhead/ -v，需要让所有测试通过。
