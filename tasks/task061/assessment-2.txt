产物不满意：
1. 在 timeoutprop.go 的 Execute 方法中，对于 hasBudget 为 false 的无预算阶段，stageCtx 通过 WithCancel(rootCtx) 创建。当根 context 超时时 select 随机选中 stageCtx.Done()，err 得到 `context.Canceled` 而非 `context.DeadlineExceeded`，导致 stageStatus 被错误设为 StageStatusFailed 且 TimeoutType 为 None，调用方无法从报告中判断这是总超时而非业务失败。原因是模型重构错误分类时只考虑了 err 来自 rootCtx 或 done 通道的路径，未处理 WithCancel 子 context 在父超时后返回 Canceled 的边界行为。修复方案是在 select 后判断：若 err 为 `context.Canceled` 且 rootCtx.Err() 非 nil，将 err 替换为 rootCtx.Err()。
