在当前项目中实现一个超时传播器功能模块。
1. 实现 context 超时在调用链中的自动传递：支持为一个调用链创建根 context 并设置总超时时间，调用链中每个子环节自动从父 context 派生子 context，父 context 超时时所有子 context 同步被取消，子 context 自身也可设置额外的超时但不得超过父 context 的剩余时间。
2. 实现各环节剩余时间的动态计算：调用链中每个环节在开始执行时能够查询当前还剩余多少可用时间，该剩余时间等于父 context 截止时间减去当前系统时间，如果剩余时间不足某个可配置的最小阈值则直接跳过该环节的执行并记录超时日志。
3. 实现超时预算分配：支持为调用链中的各个子环节预先分配时间预算，总预算之和不超过根 context 的总体超时时间，每个环节在其分配的预算内执行，超出预算时该环节被中断并将未消费的剩余预算传递给后续环节使用。
4. 实现超时原因的链路追踪：每次超时事件发生时记录超时发生的环节名称、超时类型是总超时还是预算超时、当前环节已消耗时间与分配预算的对比，最终将整条调用链的超时追踪信息汇总为一个可读的报告供调用方查询。
5. 代码实现和单测需要放在 internal/timeoutprop/ 包下，然后为该模块编写完整的单元测试，覆盖正常流程、边界条件和异常分支。
6. 运行 go test ./internal/timeoutprop/ -v，需要让所有测试通过。
7. 在 docs/timeoutprop.md 中编写模块需求文档，说明模块功能、核心结构体的职责、超时传播与预算分配流程以及使用示例。
