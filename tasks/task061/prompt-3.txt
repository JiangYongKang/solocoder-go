你实现的超时传播器模块仍存在一个问题，需要修复：
1. Execute 方法中对 hasBudget 为 false 的无预算阶段使用 WithCancel(rootCtx) 创建子 context。当根 context 因总超时而取消时 select 语句可能随机命中 stageCtx.Done() 分支，此时 err 为 `context.Canceled` 而非 `context.DeadlineExceeded`，导致超时被错误分类为业务失败（StageStatusFailed 且 TimeoutType 为 None），调用方通过 errors.Is 和查看报告都无法识别这是总超时。
2. 修复后运行 go test ./internal/timeoutprop/ -v，需要让所有测试通过。
