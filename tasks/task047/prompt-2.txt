你实现的内容安全策略引擎模块存在一些实现问题，需要修复：
1. EncodeCSS 方法中对 `<` `>` `&` 三个字符的 CSS 转义使用了双反斜杠 `\\3C` `\\3E` `\\26`，而正确的 CSS 十六进制转义序列应为单反斜杠。同一方法中对换行符等字符的转义却正确使用了单反斜杠，内部一致性都不满足，注入到 CSS 上下文中的尖括号实际上没有被正确编码。
2. processTag 方法在解析 HTML 标签名时没有处理自闭合标签中斜杠紧跟在标签名后面的情况。输入 `<br/>` 时提取到的标签名是 `br/` 而非 `br`，而默认白名单只注册了 `br`，导致合法的自闭合换行标签被静默丢弃，丢失了换行语义。
3. DataMasker 在遍历脱敏模式时从 map 取出的迭代顺序不确定。当输入内容同时匹配多个脱敏模式时（如 18 位身份证号同时命中 id_card 和 bank_card 两个模式），脱敏结果会因 map 迭代顺序的不同而随机变化，测试输出不稳定。
4. processAttributes 方法对白名单属性中的 URL 值仅做 HTML 转义而未校验协议。当输入包含 `<a href="javascript:alert(1)">` 时，a 标签和 href 属性都在白名单中，净化后输出的 javascript 伪协议未被拦截。
5. EncodeJavaScript 方法对正斜杠 `/` 做了全局转义输出 `\/`，这在 JavaScript 上下文中不是必要的安全措施，却会破坏 URL 路径和正则表达式字面量。
6. 修复后需要为上述每个问题补充对应的单元测试。
7. 运行 go test ./internal/contentsec/ -v，需要让所有测试通过。
8. 补全 docs/contentsec.md 文档中缺失的章节和使用示例代码。
