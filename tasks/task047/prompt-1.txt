在当前项目中实现一个内容安全策略引擎功能模块。
1. 实现 XSS 过滤器注册：提供可扩展的过滤器注册机制，用户可注册自定义的过滤规则，内置提供常见的 XSS 攻击模式检测规则，对输入内容进行扫描匹配，命中规则时返回危险标签或属性的位置和类型。
2. 实现输入净化规则配置：支持配置输入净化规则，包括允许保留的安全 HTML 标签白名单、允许的属性白名单、需要转义的特殊字符集合等，净化时按规则移除危险内容并对特殊字符进行 HTML 实体编码，净化后的内容返回给调用方。
3. 实现输出编码策略：根据输出上下文提供不同的编码策略，包括 HTML 实体编码、JavaScript 字符串编码、URL 参数编码和 CSS 编码四种策略，每种策略对各自上下文中危险的字符做正确的转义处理以防止注入攻击。
4. 实现敏感数据的自动脱敏：支持注册敏感数据模式（如身份证号、手机号、银行卡号、邮箱地址等），对传入的文本内容自动检测并脱敏处理，将匹配到的敏感信息替换为部分隐藏的形式，脱敏后的内容中保留部分字符用于识别但隐藏关键信息。
5. 代码实现和单测需要放在 internal/contentsec/ 包下，然后为该模块编写完整的单元测试，覆盖正常流程、边界条件和异常分支。
6. 运行 go test ./internal/contentsec/ -v，需要让所有测试通过。
7. 在 docs/contentsec.md 中编写模块需求文档，说明模块功能、核心结构体的职责、四种编码策略的适用场景以及使用示例。
