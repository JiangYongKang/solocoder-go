在当前项目中实现一个 MapReduce 分布式计算框架功能模块。
1. 实现 Map 和 Reduce 任务的分发：支持将输入数据按照可配置的分区策略切分为多个分片，每个分片分配给一个 Map 任务并行处理，Map 阶段输出的中间结果按 Key 分组后分发给对应的 Reduce 任务。
2. 实现中间数据 Shuffle：Map 任务产生的中间键值对按 Key 做哈希分区后路由到对应的 Reduce 任务，Shuffle 过程支持同步和异步两种模式，Reduce 任务在收到对应分区的全部中间数据后开始执行 Reduce 逻辑。
3. 实现任务失败重试：当 Map 或 Reduce 任务执行失败时自动重试该任务，重试次数可配置，任务重试时重新执行该任务的完整计算逻辑而非从失败点续算，超过最大重试次数后任务标记为最终失败并上报错误。
4. 实现结果合并：所有 Reduce 任务完成后将各 Reduce 任务的输出结果按需要合并为最终输出，合并策略支持简单拼接或自定义合并函数，提供最终结果的获取接口并在所有任务完成后通知调用方。
5. 代码实现和单测需要放在 internal/mapreduce/ 包下，然后为该模块编写完整的单元测试，覆盖正常流程、边界条件和异常分支。
6. 运行 go test ./internal/mapreduce/ -v，需要让所有测试通过。
7. 在 docs/mapreduce.md 中编写模块需求文档，说明模块功能、核心结构体的职责、数据从 Map 到 Shuffle 再到 Reduce 的完整流转路径以及使用示例。
