你实现的 ETL 数据管道模块存在一些实现问题，需要修复：
1. MemorySource.Fetch 方法在增量提取模式下完全不做数据过滤。管道在 updateCursor 中正确地将每批的最后时间戳或自增 ID 写入游标的 LastValue，但 Fetch 只使用游标的 LastOffset 做数组切片，完全不读取 LastValue 也不检查 cursor.Mode。增量模式形同虚设，两次运行管道会重复提取相同数据。
2. NewMemorySourceFactory 工厂函数中增量字段的设置逻辑要求 config 中 timestamp_field 和 id_field 必须同时存在且均为 string 类型才会调用 SetIncrementalFields。如果用户只用时间戳增量模式只传 timestamp_field，或只用 ID 增量模式只传 id_field，字段会被静默忽略。
3. TestPipelineWriteTimeout 测试中 WriteErrorCount < 0 的断言在 int64 类型只累加正值的语义下永远为假，是无效断言，无法验证写入超时的错误隔离逻辑是否被正确实现。
4. 修复后需要为上述问题补充对应的单元测试。
5. 运行 go test ./internal/etlpipe/ -v，需要让所有测试通过。
