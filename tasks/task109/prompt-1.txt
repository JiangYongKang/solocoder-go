在当前项目中实现一个跳表数据结构功能模块，使用泛型支持可比较的键类型和任意值类型。
1. 实现按序插入与删除：向跳表中插入键值对时按 Key 的顺序找到正确位置插入，每层以一定概率决定该节点是否向上层提升，删除节点时从所有层中移除该节点的引用。
2. 实现按 Key 精确查找：提供精确查找接口，输入一个 Key 返回对应的 Value 和是否存在标志，利用跳表的多层索引从顶层向下快速定位目标节点。
3. 实现范围查询：支持按 Key 的起始值和结束值进行范围查询，返回区间内所有键值对的有序列表，支持指定起始 Key 和结束 Key 为开区间或闭区间，支持设置返回数量上限和跳过前 N 条的偏移量。
4. 实现概率层高调整：支持在创建跳表时配置每层提升的概率因子，概率值影响跳表的层数和查询效率，高概率层多查询快但内存占用大，低概率反之。
5. 代码实现和单测需要放在 internal/skiplist/ 包下，然后为该模块编写完整的单元测试，覆盖正常流程、边界条件和异常分支。
6. 运行 go test ./internal/skiplist/ -v，需要让所有测试通过。
7. 在 docs/skiplist.md 中编写模块需求文档，说明模块功能、核心结构体的职责、跳表的层级结构与范围查询机制以及使用示例。
