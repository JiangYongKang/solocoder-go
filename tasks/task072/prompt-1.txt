在当前项目中实现一个声明式 REST HTTP 客户端功能模块，使用内存 HTTP 传输层模拟网络请求。
1. 实现请求模板注册：支持预定义 HTTP 请求模板，模板包含 HTTP 方法、基础 URL 路径和默认请求头，注册后通过模板名称即可发起请求而不需要每次重复指定方法和路径，同一名称重复注册时后者覆盖前者。
2. 实现路径参数与查询参数绑定：支持在请求模板的 URL 中使用占位符定义路径参数，发起请求时传入键值对参数自动替换占位符生成最终 URL，查询参数同样通过键值对传入后按 URL 编码规则拼接在请求 URL 末尾。
3. 实现请求头与认证信息自动注入：支持为每个请求模板配置默认请求头，发起请求时模板默认请求头与本次请求额外指定的请求头合并，额外请求头优先级高于模板默认值，支持注册全局认证提供器在每次请求前自动注入认证令牌或签名到请求头中。
4. 实现重试与超时配置：支持为每个请求模板配置请求超时时间和最大重试次数，超时时间到达后请求被取消并返回超时错误，请求失败或超时后按配置的重试次数自动重新发起请求，两次重试之间使用固定间隔等待。
5. 代码实现和单测需要放在 internal/restclient/ 包下，然后为该模块编写完整的单元测试，覆盖正常流程、边界条件和异常分支。
6. 运行 go test ./internal/restclient/ -v，需要让所有测试通过。
7. 在 docs/restclient.md 中编写模块需求文档，说明模块功能、核心结构体的职责、请求模板的生命周期与参数绑定流程以及使用示例。
