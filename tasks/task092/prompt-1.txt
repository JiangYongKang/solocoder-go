在当前项目中实现一个 Snowflake 分布式 ID 生成器功能模块。
1. 实现基于时间戳加机器 ID 加序列号的 64 位 ID 生成：使用毫秒级时间戳作为高位部分，机器 ID 作为中间位标识生成节点，序列号作为低位用于同一毫秒内的递增计数，ID 生成时如果序列号在同一毫秒内耗尽则阻塞等待下一毫秒。
2. 实现时钟回拨处理：检测当前时间戳是否小于上一次生成 ID 时记录的时间戳，如果发生时钟回拨则根据回拨偏移量的不同采取不同策略，小幅度回拨时短暂等待时钟追上，大幅回拨时拒绝生成 ID 并返回错误说明回拨幅度的具体数值。
3. 实现 ID 解析为各字段的工具函数：提供工具函数从生成的 64 位 ID 中解析出时间戳、机器 ID 和序列号三个原始字段，解析结果可用于问题排查和日志审计。
4. 代码实现和单测需要放在 internal/snowflake/ 包下，然后为该模块编写完整的单元测试，覆盖正常流程、边界条件和异常分支。
5. 运行 go test ./internal/snowflake/ -v，需要让所有测试通过。
6. 在 docs/snowflake.md 中编写模块需求文档，说明模块功能、核心结构体的职责、64 位 ID 的位分配方案、时钟回拨的处理策略以及使用示例。
