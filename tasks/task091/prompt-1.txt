在当前项目中实现一个短链接生成器功能模块。
1. 实现自增 ID 策略：提供基于自增整数的短码生成策略，自增 ID 转换为短码字符串使用 Base62 编码或其他紧凑字符集，确保生成的短码唯一且长度随 ID 增长而逐步增加。
2. 实现哈希策略：提供基于输入的原始 URL 计算哈希摘要并截取指定长度作为短码的策略，支持配置哈希算法和截取长度，哈希冲突时自动调整截取位置或对原始 URL 做微小变化后重新计算。
3. 实现随机字符串策略：提供基于随机字符串生成短码的策略，支持配置字符集和短码长度，随机生成的短码需检查唯一性，如果与已有短码冲突则重新生成直到获得唯一短码。
4. 实现自定义短码：允许调用方在创建短链接时指定自定义短码，自定义短码需要校验格式合法性和唯一性，如果自定义短码已被占用则返回错误并提示冲突。
5. 实现访问统计计数：每次通过短码获取原链接时自动递增该短码的访问次数计数器，提供接口查询单个短码的累计访问次数以及全部短码的访问次数汇总。
6. 实现短码冲突时的重试生成：自增 ID 策略以外的两种策略在生成短码时如果出现冲突应自动重试生成，重试次数可配置，超过最大重试次数仍冲突时返回错误。
7. 代码实现和单测需要放在 internal/shortlink/ 包下，然后为该模块编写完整的单元测试，覆盖正常流程、边界条件和异常分支。
8. 运行 go test ./internal/shortlink/ -v，需要让所有测试通过。
9. 在 docs/shortlink.md 中编写模块需求文档，说明模块功能、核心结构体的职责、三种短码策略的选型对比以及使用示例。
