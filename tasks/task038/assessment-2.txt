产物不满意：
1. expiryLoop 的 defer 函数中先执行 wg.Done() 后设置 expiryRunning = false，Stop 的 wg.Wait() 在 Done 后立即返回，此时 expiryRunning 仍为 true。StartStopNoPanic 等测试中 Start 紧接着 Stop 调用时发现 expiryRunning 为 true 会认为过期协程正在运行而直接返回，不启动新的过期循环。应在 defer 中先设置 expiryRunning = false 再调用 wg.Done()。
2. expireInstances 方法在删除过期实例后才调用 buildEventLocked 构建 expire 事件通知，传入订阅者的是过期后的存活实例列表。当某服务全部实例过期时 expire 事件中 Instances 为空列表，订阅者无法获知哪些实例被逐出。正确做法是在删除实例前先通过 buildEventLocked 构建过期前快照，再将事件发送出去。
3. TestMultiServiceExpireNotificationAtomic 中定义了 atomicViolation 变量但从未被任何代码递增为非零值，assert 语句 atomic.LoadInt32(&atomicViolation) != 0 恒为 false，测试始终通过。它不验证任何原子性或通知一致性，仅运行了一个并发心跳场景后退出，属于不提供有效测试覆盖的虚假测试用例。
4. TestConcurrentStartStop 启动了 10 个 goroutine 并发调用 Start 后直接等待 wg 结束，没有验证 expireLoop 是否被正确启动了恰好一次，也没有检查 expiryRunning 的状态是否一致。该测试仅验证了没有 panic，无法覆盖提示词第 4 条要求验证的并发 Start/Stop 交叉语义。
