# Benchfrm 基准测试框架模块

## 模块概述

`internal/benchfrm` 包提供了一个功能完整的基准测试框架，支持对 Go 函数进行性能基准测试。框架提供了重复运行、预热阶段、内存分配统计、多组对比报告和性能回归自动检测等核心功能。

## 核心功能

### 1. 重复运行统计
支持对被测函数执行指定次数的重复运行，统计每次运行的耗时，最终输出：
- 平均耗时（Mean Duration）
- 最快耗时（Min Duration）
- 最慢耗时（Max Duration）
- 标准差（Std Deviation）

### 2. 预热阶段
在正式计时前先执行若干次预热迭代，让 JIT 编译、CPU 缓存、内存分配器等运行时因素趋于稳定。预热阶段的执行结果不计入最终统计。预热次数和正式运行次数均可独立配置。

### 3. 内存分配统计
在每次基准运行期间统计内存分配情况，输出：
- 每次运行的平均分配字节数（Mean Alloc Bytes）
- 每次运行的平均分配次数（Mean Alloc Count）
- 每次操作的分配次数（Allocs Per Op）
- 每次操作的分配字节数（Bytes Per Op）

内存统计仅在正式运行期间累计，不受预热阶段影响。可通过配置启用或禁用。

### 4. 多组对比报告
支持注册多个不同的被测函数或同一函数的不同参数配置作为多个对比组。各组独立运行后生成对比报告，报告列出每组的所有统计指标以及各组
